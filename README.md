# cyrillic5x7 — драйвер кирилиці 5×7 для Adafruit_GFX

Компактний заголовний драйвер (`cyrillic5x7.h`) для виводу української кирилиці (включно з **І, Ї, Є, Ґ**) разом зі стандартними ASCII-символами на монохромні OLED/LCD-дисплеї (SSD1306, SH1106 тощо), що працюють через бібліотеку **Adafruit GFX**.

У репозиторії також міститься тестовий скетч для ESP32, який створює Wi-Fi точку доступу з веб-формою для швидкої перевірки відображення тексту з телефона.

---
Встановлення:
1. Встановіть у середовищі розробки бібліотеку **Adafruit GFX Library** (та бібліотеку вашого дисплея, наприклад **Adafruit SSD1306**).
2. Скопіюйте файл `cyrillic5x7.h` у папку вашого проєкту та підключіть його:
   #include <Adafruit_GFX.h>
   #include <Adafruit_SSD1306.h>
   #include "cyrillic5x7.h"

Основні функції:
printCyrillic(Adafruit_GFX &gfx, String text, int16_t x, int16_t y, uint8_t size = 1)
Виводить рядок у кодуванні UTF-8 починаючи з координат (x, y) із масштабом size.

drawCyrillicChar(Adafruit_GFX &gfx, int index, int16_t x, int16_t y, uint8_t size)
Малює окремий символ за його індексом у таблиці cyrillic5x7Bitmaps (0 — пробіл, 1–32 — А–Я, 33 — І, 34 — Ї, 35 — Є, 36 — Ґ).
